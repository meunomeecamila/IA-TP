Visualizador interativo da base de treino

Esta página deixa você explorar a base de dados do trabalho sem abrir o notebook. A base de treino (base_treino.csv) tem 69.833 linhas e 50 colunas, e a tabela mostra linhas escolhidas à mão para ilustrar cada característica que analisamos: tipos de atributo, inconsistências, redundâncias, desbalanceamento e valores extremos.

Três palavras para começar

Instância
Uma linha da tabela: uma conexão de rede registrada na base.
Atributo
Uma coluna da tabela: uma característica medida dessa conexão, como o protocolo ou o número de bytes.
Classe
A última coluna: diz se a conexão é normal ou uma anomalia. É o que os modelos vão tentar prever.

Como usar

  1. Em Colunas, escolha um grupo de atributos. A tabela passa a mostrar só as colunas desse grupo (a classe aparece sempre).
  2. Em Instâncias, escolha uma característica da base. A tabela passa a mostrar só as linhas que ilustram esse ponto.
  3. Leia o quadro de explicação que aparece abaixo dos seletores: ele diz o que a categoria escolhida significa e por que ela importa.
  4. Clique em uma linha da tabela (ou use Tab e Enter) para ver por que ela foi escolhida.

1. Colunas: o que mostrar na tabela

Cada grupo tem uma cor. Em "Todos os atributos", o cabeçalho de cada coluna usa a cor do grupo dela.

2. Instâncias: quais linhas mostrar

Cada característica também tem uma cor, usada para marcar as linhas e as células que a ilustram.

Tabela

  • Célula com fundo colorido: onde está o ponto de interesse da instância
  • Linha selecionada
  • Primeira coluna (linha): posição da instância em base_treino.csv, começando em 0
  • Role a tabela para o lado para ver todas as colunas
